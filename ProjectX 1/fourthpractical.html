📖 Theory

🔑 What is Authentication?

Authentication is the process of verifying the identity of a user, device, or system before granting access to resources. It answers the question: "Are you who you claim to be?"

Authentication is the first line of defense in any security system. Without proper authentication, unauthorized users can gain access to sensitive data and systems.

📌 3 Factors of Authentication:
• Something you know — Password, PIN
• Something you have — OTP, Smart card, Token
• Something you are — Fingerprint, Face ID (Biometrics)

🔒 What is Password Security?

A password is a secret string of characters used to authenticate a user. Password security refers to the practices and policies that ensure passwords are strong enough to resist attacks.

A weak password (like "1234" or "password") can be cracked in seconds. A strong password with mixed characters takes years or even centuries to crack using brute force.

💥 What is a Brute Force Attack?

A brute force attack is a trial-and-error method where an attacker systematically tries every possible combination of characters until the correct password is found.

For a 4-digit numeric PIN: only 10,000 combinations — cracked in seconds.
For an 8-character mixed password: 95⁸ ≈ 6.6 trillion combinations — takes much longer.

📌 Why strong passwords resist brute force: Each additional character type (uppercase, special chars) multiplies the number of possible combinations exponentially.

📖 What is a Dictionary Attack?

A dictionary attack uses a pre-built list of common words, phrases, and passwords (like "password123", "admin", "qwerty") to guess the password. It is faster than brute force but only works against common or predictable passwords.

Strong passwords that avoid dictionary words and include random special characters are immune to dictionary attacks.

📋 Password Policy

A password policy is a set of rules that enforces the creation of strong passwords. Organizations implement password policies to protect their systems. Common rules include:

• Minimum length of 8 characters
• Must contain uppercase and lowercase letters
• Must contain at least one digit (0–9)
• Must contain at least one special character (#, %, &, @)
• Must not contain the username or common words
• Must be changed every 90 days

🛠️ C Language Functions Used

The program uses standard C library functions from <ctype.h> and <string.h>:

• strlen(pwd) — returns length of the password string
• isupper(ch) — returns non-zero if character is uppercase (A–Z)
• islower(ch) — returns non-zero if character is lowercase (a–z)
• isdigit(ch) — returns non-zero if character is a digit (0–9)
• strchr(str, ch) — searches for character in string; returns pointer if found, NULL if not

⚙️ Algorithm

  1. START
  2. Declare character array password[50] and integer flags: hasUpper, hasLower, hasDigit, hasSpecial — all initialized to 0
  3. Define special characters string: specials = "#%&@"
  4. Prompt user: "Enter password:" and read input using scanf()
  5. Check strlen(password) > 8 — if false, print "Too short" and exit
  6. Loop through each character of the password using a for loop
  7. Inside loop: if isupper(ch) → set hasUpper = 1
  8. Inside loop: if islower(ch) → set hasLower = 1
  9. Inside loop: if isdigit(ch) → set hasDigit = 1
  10. Inside loop: if strchr(specials, ch) != NULL → set hasSpecial = 1
  11. After loop: check if hasUpper && hasLower && hasDigit && hasSpecial are all 1
  12. If all conditions true → print "✅ Strong Password!"
  13. If any condition false → print specific failure reason
  14. END

💻 Program Code

The following C program validates a password against all strong password rules. It checks length, uppercase, lowercase, digit, and special character requirements.

📄 password_validator.c — C Program 
/*
 * Practical 4 — Strong Password Authentication
 * Course: Network & Information Security (316317)
 * Description: Validates password strength using C
 */

#include <stdio.h>
#include <string.h>
#include <ctype.h>

int isStrongPassword(const char *pwd) {

    int len       = strlen(pwd);
    int hasUpper   = 0;
    int hasLower   = 0;
    int hasDigit   = 0;
    int hasSpecial = 0;
    const char *specials = "#%&@";

    /* Rule 1: Length must be more than 8 */
    if (len <= 8) {
        printf("❌ Too short! Password must be more than 8 characters.\n");
        return 0;
    }

    /* Rule 2-5: Check each character */
    for (int i = 0; i < len; i++) {
        char ch = pwd[i];

        if      (isupper(ch))          hasUpper   = 1;
        else if (islower(ch))          hasLower   = 1;
        else if (isdigit(ch))          hasDigit   = 1;
        else if (strchr(specials, ch)) hasSpecial = 1;
    }

    /* Check all rules and report missing ones */
    if (!hasUpper)   { printf("❌ Missing uppercase letter (A-Z).\n");      return 0; }
    if (!hasLower)   { printf("❌ Missing lowercase letter (a-z).\n");      return 0; }
    if (!hasDigit)   { printf("❌ Missing digit (0-9).\n");               return 0; }
    if (!hasSpecial) { printf("❌ Missing special character (#, %%, &, @).\n"); return 0; }

    return 1; /* All rules passed */
}

int main() {
    char password[50];

    printf("========================================\n");
    printf("   Strong Password Authentication Tool\n");
    printf("========================================\n");
    printf("Enter password: ");
    scanf("%s", password);
    printf("\n--- Checking Password Strength ---\n");

    if (isStrongPassword(password)) {
        printf("✅ STRONG PASSWORD! Access Granted.\n");
    } else {
        printf("⚠️  WEAK PASSWORD! Please try again.\n");
    }

    printf("========================================\n");
    return 0;
}

🐚 Bonus: Shell Script Version

📄 password_check.sh — Shell Script (Bash) 
#!/bin/bash
# Practical 4 — Strong Password Validator (Shell Script)

echo "Enter password: "
read -s password   # -s hides input
echo

len=${#password}   # get length

# Rule 1: Length check
if [ $len -le 8 ]; then
    echo "❌ Too short! Must be more than 8 characters."
    exit 1
fi

# Rule 2-5: Check character types using regex
if ! echo "$password" | grep -q '[A-Z]'; then
    echo "❌ Missing uppercase letter."; exit 1
fi

if ! echo "$password" | grep -q '[a-z]'; then
    echo "❌ Missing lowercase letter."; exit 1
fi

if ! echo "$password" | grep -q '[0-9]'; then
    echo "❌ Missing digit."; exit 1
fi

if ! echo "$password" | grep -q '[#%&@]'; then
    echo "❌ Missing special character (#, %, &, @)."; exit 1
fi

echo "✅ STRONG PASSWORD! Access Granted."

⚠️ Precautions

Use scanf("%s", password) carefully — it stops at whitespace. Use fgets() if spaces are allowed in passwords.
Always initialize flag variables (hasUpper, hasLower, etc.) to 0 before the loop.
The condition is length > 8 (strictly greater than), not >= 8. A password of exactly 8 characters is rejected.
Include both <ctype.h> (for isupper, islower, isdigit) and <string.h> (for strlen, strchr) headers.
Never store passwords in plain text in real applications — always hash them using SHA-256 or bcrypt.
In the shell script, use read -s to hide password input from the terminal screen.
Avoid using common words or personal information (name, birthdate) in passwords even if they pass validation.
The special characters are limited to #, %, &, @ as per the practical requirement — extend the specials string for real-world use.

🧠 Viva Questions & Answers

Q1. What is Authentication? ▾
Authentication is the process of verifying the identity of a user or system before granting access. It confirms "you are who you claim to be." Common methods: password, OTP, biometrics.
Q2. What is a Strong Password? ▾
A strong password has: more than 8 characters, at least one uppercase letter (A–Z), one lowercase letter (a–z), one digit (0–9), and one special character (#, %, &, @). It avoids dictionary words and personal info.
Q3. What is the difference between Authentication and Authorization? ▾
Authentication verifies who you are (identity check — login with password). Authorization determines what you can do (access control — admin vs. regular user). Authentication always happens before authorization.
Q4. What is a Brute Force Attack? ▾
A brute force attack tries every possible combination of characters until the correct password is found. A 4-digit PIN has 10,000 combinations (cracked instantly). An 8+ character mixed password has trillions of combinations — making brute force impractical.
Q5. What is a Dictionary Attack? ▾
A dictionary attack uses a pre-built list of common passwords (like "password", "admin123", "qwerty") to guess the password. It's faster than brute force but fails against random, complex passwords that don't contain common words.
Q6. What does isupper() function do in C? ▾
isupper(ch) is a function from <ctype.h> that returns a non-zero value if the character ch is an uppercase letter (A–Z), and 0 if it is not. Example: isupper('A') = non-zero, isupper('a') = 0.
Q7. What does strchr() function do? ▾
strchr(str, ch) from <string.h> searches for character ch in string str. It returns a pointer to the first occurrence if found, or NULL if not found. Used here to check if a character is a special character.
Q8. Why is password length important? ▾
Longer passwords have exponentially more combinations. Each additional character multiplies the search space. An 8-character password with 95 possible characters has 95⁸ ≈ 6.6 trillion combinations. A 12-character password has 95¹² ≈ 540 quadrillion combinations.
Q9. What is Password Salting? ▾
Password salting adds a random string (salt) to a password before hashing it. This ensures two identical passwords produce different hashes, preventing rainbow table attacks. Example: "password" + "xK9m" → hash("passwordxK9m").
Q10. What header files are used in this program and why? ▾
<stdio.h> — for printf() and scanf(). <string.h> — for strlen() and strchr(). <ctype.h> — for isupper(), islower(), isdigit(). All three are required for this password validation program.
Q11. What is Multi-Factor Authentication (MFA)? ▾
MFA requires two or more verification factors: something you know (password), something you have (OTP/token), something you are (biometric). Even if a password is stolen, MFA prevents unauthorized access.
Q12. What is the difference between isdigit() and isnumber()? ▾
isdigit(ch) is a standard C function from <ctype.h> that checks if a character is a decimal digit (0–9). isnumber() is not a standard C function — it does not exist in standard C. Always use isdigit() in C programs.
Q13. Why should passwords never be stored in plain text? ▾
If a database is breached and passwords are in plain text, all accounts are immediately compromised. Passwords should be stored as hashed values (using SHA-256, bcrypt). Even if the hash is stolen, the original password cannot be easily recovered.
Q14. What is the purpose of the -s flag in shell script's read command? ▾
The -s flag in read -s password makes the input silent — characters typed are not displayed on the terminal. This prevents shoulder surfing (someone watching your screen) from seeing the password as it's typed.
Q15. What is a Rainbow Table Attack? ▾
A rainbow table attack uses precomputed hash values for millions of common passwords. The attacker compares stolen hashes against the table to find matches instantly. Password salting defeats rainbow table attacks because each salt produces a unique hash.
